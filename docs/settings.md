# Settings

Hive keeps its settings in the store. Run `hive settings` to read every setting with its value, or `hive settings get NAME` to read one. To change one, run `hive settings set NAME VALUE` or use the console's [Settings](console.md#settings) page; a value the setting does not take is refused with the reason. The command has its own entry: [`settings`](commands.md#settings).

This page is generated by `scripts/gen-reference.sh` from what `hive settings list --json` prints. Do not edit it by hand: change the description in the code, then run the script again. That list also carries each setting's rule (`kind`, `min`, `choices`), which this page leaves out.

Each section below is one family: the settings that share the part of their name before the first dot. The families come in alphabetical order. General comes first and holds the settings that belong to no family. A default of empty means the setting has no value until you set one.
