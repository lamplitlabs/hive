# Guides

Each guide takes one job from start to finish: what to click in the console, what to type in a terminal, and how to tell that it worked.

New to Hive? [Install it](../../README.md#install), then follow the first
three guides in order. After that, pick the one you need. If a word is
new, [Concepts](../concepts.md) explains how the parts fit.

## Start here

1. [Set up your first project](first-project.md): connect a model
   provider, register your repository and start the runner.
2. [A tour of the console](console-tour.md): each page of the console and
   what you do there, with pictures.
3. [Give a task and steer it](tasks.md): write a task an agent can act
   on, follow it, answer the lead, change it or cancel it.

## Every day

- [Review and merge the work](pull-requests.md): where finished work
  arrives, what the reviewing agent decided, and how to merge it or ask
  for changes.
- [Answer what waits for you](what-needs-you.md): the round through the
  console that shows every question, proposal and request that waits for
  you, and how to answer each.
- [Work with an agent in a session](sessions.md): talk to one agent turn
  by turn, and bring the coding agent you already use into the Hive.

## Give the agents more to work with

- [Run work on a schedule](schedules.md): a job an agent repeats, or a
  check script the runner runs without a model.
- [Seat role leads on a project](role-leads.md): a lead for one concern,
  such as docs or security, beside the project's own lead.
- [Give agents skills and tools](skills-and-tools.md): written
  instructions your agents load, and MCP servers they can call.
- [Choose models and set budgets](models.md): a provider, a key or a
  local server, a model for each kind of run, and the limits of a job.
- [Add a second machine](add-a-machine.md): pair another machine so jobs
  run where the right tools are.

## Stay in control

- [Set the rules agents work under](rules.md): the constitution, the
  three tiers, the paths that are yours alone, and the kill switch.
- [Turn on the self-improvement loop](self-improvement-loop.md): what the
  loop does, the gates it must pass, turning it on, and turning it off.

## Keep it running

- [Keep Hive running, updated and backed up](operations.md): services,
  updates, backups, moving a checkout and removing Hive.
- [Troubleshooting](troubleshooting.md): where to look first, and the fix
  for each common symptom.
